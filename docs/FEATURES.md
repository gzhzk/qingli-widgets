# 当前功能和外观

本文件描述当前源码中的行为，运行验收状态见 ../VALIDATION.md。

日历默认周一开头。所有月份采用固定六行、42格和固定卡片高度，跨月日期浅灰，翻月不按月份行数改变高度。年月在左，当天农历在右；翻月时农历仍显示电脑当天日期。月份标题13、字重500，日期10.5、农历9；这些是缩放前的布局值。

当天农历离线计算，不产生农历联网请求或额外进程。数据范围按原实现为1901-02-19至2101-01-28，超出范围隐藏。支持闰月；十一月/十二月显示冬月/腊月。日期正确性及不同DPI下长文本显示尚待本次实机验收。

右键日历可选择经典红、湖蓝、青色、薄荷绿和紫色。自定义面板支持点击色相条和滚轮微调，不支持按住拖动；×收起，恢复红色重置配色。颜色保存到 @Resources/Refined/Accent.inc；配色操作保留当前翻月位置。

右键卡片切换柔透/清晰材质，写入 @Resources/Refined/Material.inc 并刷新两卡。材质是半透明填充，不是系统背景模糊。默认缩放0.9；字体仅使用系统已有字体。

天气按实际日期决定今天/明天，后续显示星期。Open-Meteo 使用响应中的城市时区偏移，和风使用已经裁剪到当地今天的预报。数值进行取整，天气码映射为本地图片；QWeather 城市 v7 未提供的降水概率不会人为补出。

点击天气文字、温度或大图标可刷新；AutoIP 下点击城市/定位图标会重新定位后刷新，Manual 下点击城市直接刷新天气。和风模式另有忙碌、冷却及完成反馈；不能把这一反馈承诺推广为两种天气来源完全一致。
